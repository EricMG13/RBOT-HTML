# CP-OS register scope

Registers a module does not write in this transport (owner, 2026-11-13; ruling
`docs/rulings/2026-11-13-appendix-and-routing-scope.md`). One section per module, sent as the last
section of that module's method block. Each list is the registers that have a method id and that
no later module, check, chart, the Forecast page or the library read in either retained Sol run
(`docs/sweeps/2026-11-13-optimisation-review/appendix-inventory.md`). The title beside each id is
the method's own.

## CP-0

Register scope in this transport: do not write P5 Parse jobs record; T3 Source hierarchy; T5 Gaps and conflicts. Any figure, limitation or conclusion you draw from that work goes in a register you do write, in `## Calculations` or in `## Gaps`. A register named here is not required by the method's `required_register_ids`, `appendix_contract`, lossless profile or completeness check in this transport: when you run those checks yourself, do not restore it and do not block for want of it.
